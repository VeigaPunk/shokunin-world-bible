## Findings & named debt

- **Decision:** Translator name alone, without a reliable link to a named source work, fails R5 support. A later reprint can qualify only if an auditable, item-specific record identifies the actual delivered reprint and its edition/year (with stable identifier or copy locator), names the translator and source work, and ties the cited passage to that translation; verify the excerpt against that exact copy. Record the specific printing and record citation. If no source-work link is established, record `Source text/version: unidentified; unverified`; if the work is known but the exact source edition/version is not, name the work and record that limitation separately. A generic re-issue note, untraceable secondary entry, translator name, or anchor alone fails the reliability threshold. A qualifying tie permits support only for the checked wording in that identified reprint; it does not prove the text matches an earlier printing or support claims about earlier wording/edition-specific variants without independent identification and comparison.
- **JDEP2 worked case:** a named translator plus only a generic “2011 reprint of the 1901 translation” re-issue note, with `Source text/version: unidentified; unverified`, fails R5 source-claim support unless an item-specific record supplies the required link. Keep `Delivery mode: translation`; do not mislabel a delivered translation as absent. This is a prospective manual governance screen, not a mechanical source-fidelity finding.
- **Named debt — R9 receipt parity:** JDEP2's exact replay shows `support_check.py` counts an unverified-version translation as `SOURCE-SUPPORT 1/1` and `RESULT PASS`. This C3 patch changes no checker and must not be read as making that receipt enforce this editorial rule; parity remains for the appropriate C2/integration follow-up.
