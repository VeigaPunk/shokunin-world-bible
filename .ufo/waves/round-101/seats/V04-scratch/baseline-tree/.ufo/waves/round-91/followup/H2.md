`census.py` as run (final path-style fix included):

```python
#!/usr/bin/env python3
"""H2 independent fixture census for lore-shokunin round-91 follow-up.

tree  <root> <checker> <out.json> : run <checker> once per direct child dir of
      <root>/corpus/fixtures (relative fixture arg, cwd=<root>).
archive <scratch> <out.json>      : consume a `git archive --format=tar <rev>
      corpus/fixtures` stream on stdin; materialize each fixture into
      <scratch>/root one at a time (single reused path, inode-frugal), run the
      check_bible.py member extracted from the same stream, record, remove.
"""
import argparse
import hashlib
import json
import pathlib
import shutil
import subprocess
import sys
import tarfile


def run(checker, fixture_arg, cwd):
    proc = subprocess.run(
        [sys.executable, '-I', str(checker), str(fixture_arg)],
        cwd=str(cwd), stdout=subprocess.PIPE, stderr=subprocess.PIPE)
    return {
        'exit': proc.returncode,
        'stdout_sha256': hashlib.sha256(proc.stdout).hexdigest(),
        'violation_count': sum(1 for line in proc.stdout.splitlines()
                               if line.startswith(b'VIOLATION:')),
        'stderr_len': len(proc.stderr),
    }


def summarize(rows, source, checker):
    exits = {}
    for row in rows.values():
        exits[row['exit']] = exits.get(row['exit'], 0) + 1
    return {
        'source': source,
        'checker': str(checker),
        'checker_sha256': hashlib.sha256(pathlib.Path(checker).read_bytes()).hexdigest(),
        'fixture_count': len(rows),
        'exit_counts': {str(k): exits[k] for k in sorted(exits)},
        'violation_lines': sum(r['violation_count'] for r in rows.values()),
        'stderr_nonempty_count': sum(1 for r in rows.values() if r['stderr_len']),
        'rows': rows,
    }


def write(out, payload):
    raw = json.dumps(payload, indent=1, sort_keys=True) + '\n'
    pathlib.Path(out).write_text(raw, encoding='utf-8')
    digest = hashlib.sha256(raw.encode()).hexdigest()
    print(f"wrote={out} bytes={len(raw.encode())} sha256={digest}")
    print(f"fixture_count={payload['fixture_count']} exit_counts={payload['exit_counts']} "
          f"violation_lines={payload['violation_lines']} "
          f"stderr_nonempty={payload['stderr_nonempty_count']} "
          f"checker_sha256={payload['checker_sha256']}")


def tree_mode(root, checker, out):
    root = pathlib.Path(root)
    rows = {}
    for child in sorted(x for x in (root / 'corpus/fixtures').iterdir() if x.is_dir()):
        rel = f'corpus/fixtures/{child.name}'
        rows[rel] = run(checker, rel, root)
    write(out, summarize(rows, str(root), checker))


def archive_mode(scratch, out):
    scratch = pathlib.Path(scratch)
    checker = scratch / 'archive-check_bible.py'
    groups = {}
    top = {}
    with tarfile.open(fileobj=sys.stdin.buffer, mode='r|') as stream:
        for member in stream:
            if not member.isfile():
                continue
            parts = member.name.split('/')
            if len(parts) == 3:
                top[parts[2]] = stream.extractfile(member).read()
            elif len(parts) > 3:
                groups.setdefault(parts[2], {})['/'.join(parts[3:])] = (
                    stream.extractfile(member).read())
    checker.write_bytes(top['check_bible.py'])
    root = scratch / 'root'
    rows = {}
    for name in sorted(groups):
        if root.exists():
            shutil.rmtree(root)
        rel = f'corpus/fixtures/{name}'
        for member_rel, blob in sorted(groups[name].items()):
            target = root / rel / member_rel
            target.parent.mkdir(parents=True, exist_ok=True)
            target.write_bytes(blob)
        rows[rel] = run(checker, rel, root)
    if root.exists():
        shutil.rmtree(root)
    write(out, summarize(rows, f'git archive stream ({len(groups)} fixture dirs)', checker))


def main():
    parser = argparse.ArgumentParser()
    sub = parser.add_subparsers(dest='mode', required=True)
    t = sub.add_parser('tree')
    t.add_argument('root')
    t.add_argument('checker')
    t.add_argument('out')
    a = sub.add_parser('archive')
    a.add_argument('scratch')
    a.add_argument('out')
    ns = parser.parse_args()
    if ns.mode == 'tree':
        tree_mode(ns.root, ns.checker, ns.out)
    else:
        archive_mode(ns.scratch, ns.out)


if __name__ == '__main__':
    main()
```

## Findings & named debt

1. **C1 census claim reproduced independently at three levels.** "0 changed + 2 new of 166" is confirmed by my own harness: dir-set 164→166 with the two additions and zero removals/changes; behavioral tuples identical on all 164 common dirs; and the e97613c-vs-delivered discriminator set is exactly the pair — so a silent revert of either repaired gate fails the census on those rows (and on the checker hash via the C9 pin). The delivered checker is byte-identical to the baseline blob (`ff9fd2aa...`), so r91's checker-untouched claim also holds.
2. **Precision note on "0 changed": dir/output-level, not file-level.** The delivered tree's `corpus/fixtures` also carries 3 modified aux `.md` maps (r87-myth-cluster, r88-m3-maya-cluster, r89-inspiration-paraphrase) and 12 added files; 0 fixture JSON files changed. The three maps are the documented C2 wording/Inventory edits and are checker-invisible, but a reader must not generalize "0 changed" to "no file under corpus/fixtures changed". Named for the closure wording.
3. **Named method debt — census invocation style.** Tuple hashes for the 5 missing-file fixtures depend on the path argument style (verified by my first-run artifact). Any future census/harness must pin relative-from-root invocation (as B1/B2/H4/test-suite do) or exactly those 5 rows will mismatch with a false "changed" alarm. Suggested: record the invocation style alongside any future census receipt, and keep the C9-style pin wording explicit about it.
4. **Discrimination is textual, not numeric.** Both fixtures keep exit=1 and identical violation counts under both checkers; only line text changes (hedged → definite on the null chain; hedge removed from the tick line while the chain-break hedge stays). The durable census tuples (sha256) and the checker-hash pin are what make a revert detectable — worth stating wherever the C9 watch is summarized.
5. **B3 coverage note (not a gap).** B3 pins the e97613c side with scratch probes: its null probe output is byte-identical to the durable null fixture (3a337ba4...), while its tick probe pins previous-tick 2 against the fixture's previous-tick 3 — same repaired shape, different numeric pair; the durable tick fixture's own e97613c hash is pinned in its README and matched my independent run. No coverage gap found.
6. **Sibling-verification note.** `H4-census.json` (and H4's summary fields) existed before this seat's first tool call; my numbers were produced by my own harness and agree with it 100% — reported as a tie-out, not inheritance. H3/H4/JCAL5 follow-up artifacts arrived during the two wait checks and agree on every overlapping number; none was needed as input.
7. **No harm found.** No axis is harmed by this seat's measurements: all deltas are additions-only at directory level with the checker unchanged; the only caveat is the interpretation note (item 2) and the invocation-style pin (item 3).
