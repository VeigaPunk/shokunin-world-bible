## Findings (severity-ranked)

1. **Low — the two modes are one computation with two labellings.** `--checker`
   selects which run is displayed and how the final exit maps
   (`discriminate_check.py:92-141`); the pass/fail conjunction computed on the
   delivered file is identical in both modes. Probes S1 and S4 confirm the
   predicted behaviour. Consequence: exit 2 from `--checker e97613c` means
   "the baseline control fails the pinned delivered semantics while the on-disk
   checker is intact" — it is a confirmation of the differential, not evidence
   that a current-tree revert was caught. A real revert yields exit 1
   INCONCLUSIVE in that mode. Wording is potentially misleading; documented
   outcome text in `corpus/tools/README.md:74-82` is accurate and the registry
   row's `0/1/2` map is honest.
2. **Low — registry row's verdict map cannot distinguish argparse misuse from a
   regression.** Both are exit 2. The tools README addendum covers it ("exit 2
   alone is not proof of regression"); the SKILL.md registry row does not carry
   that caveat. Documentation-only gap; no false verdict is produced by a valid
   invocation.
3. **Low — historical digest observation, outside this claim.** Two digests in
   `.ufo/waves/round-91/patches/B3-before-state.json` (`4283f695…`, `66ed1438…`)
   do not match my reproduced tick-fixture outputs under any of five framings
   (raw, rstrip, +newline, stdout+stderr, with exit code). The later C5/C10
   pins and my reproduction agree. Likely a pre-amendment capture (r91's
   `c2ab3d0` fixture amendment); the delivered gate does not depend on those
   digests, and no current verdict changes. Named, not chased: r91 evidence
   history is not my scoped claim.
4. **Named debt (not a defect of this claim) — no protocol self-test.** PROTOCOL
   §Gate standard requires a self-invocation mode with persisted expectations;
   `discriminate_check` has none and the registry says so explicitly rather
   than implying a pass. Independent replay + my scratch probes are capability
   evidence standing in for this report only; they do not close the debt.
