- **R8 — both proposals govern the unrecorded-influence case, but materially diverge on the provisional marker.** D1 opens a neutral review and immediately marks the affected element `external-only / unverified inspiration`, even though opening the review is not a finding of source use. D2 records `possible influence: unverified` as a question and reserves the element marker for confirmed use/general-motif disposition. D1's trigger has observable branches (specific source correspondence or an explicit creator/reviewer claim with no contemporaneous record); D2 likewise requires evidence beyond generic similarity or asserted consultation. The threshold “beyond a commonplace motif” remains editorial, and D2's worked example says to ask the author despite describing only a commonplace motif and no consultation evidence—clarify whether that is an optional inquiry or a formal trigger. D1's example does meet its trigger because the creator raises possible influence.
- **R9 — owners and triggers are explicit, but the proposals fork on eligibility.** D1 withholds R5 support until the translation is tied to an identified source text/version. D2 permits narrowly scoped support for the translator's rendering when a reliable bibliographic record ties it to a named source work even though the printing/version is unknown; without that tie, support fails. The JDEP2 probe (translator named, source/version unrecorded, no demonstrated bibliographic tie) is not eligible under either proposal. D1's command checks textual completeness only; D2 has no executable example command in its patch, only prose examples. Integration must select and state the work-level-tie threshold; do not merge the two R9 outcomes silently.
- **R10 — both proposals govern the different-occasion near-miss.** Matching names/IDs trigger comparison, not identity; different source-supported occasions do not become a contradiction unless the same referent, field, and occasion are established and the claims conflict. Both require an incoming-cluster README record for dismissed/candidate overlaps and reserve the live register for supported incompatible pairs. The JDEP2 two-cluster probe has event ID `moon-basin-vow`, locations `mother-tide-gate`/`reed-arch`, and Saltmonth 4/9; both structural checks are clean, but this is not a proof of semantic identity.
- **Retroactivity:** no proposal requires reclassifying the landed r87/r88 data.
