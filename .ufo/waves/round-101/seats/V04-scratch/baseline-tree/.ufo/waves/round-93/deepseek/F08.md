   documented invocation.** The guard tests the phrases against the whole checked
   file, which in the documented run is the dossier that hosts the checker code,

   affect the load-bearing digest gate. Not a regression: the pre-round tree had no

   mutated record.** Measured: on a dossier whose `Gate result` carries the appended

   exit 0 with 5/5. The supersession note is explicit ("This dated correction
   supersedes the replay instructions above"), and the block also depends on the
   round-92 patch path, but a reader who runs the first block gets a green light.
   Candidate for a future round's cleanup (proposal only; L1 owns admission).
