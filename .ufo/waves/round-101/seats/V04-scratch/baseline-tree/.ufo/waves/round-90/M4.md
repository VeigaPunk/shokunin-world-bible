## Findings & named debt

- **Paraphrase/summary gate: improved.** With the excerpt-level declarations and all three `gate-witness` rows consistently changed, matching anchors were classified `retelling-support-only`; the source-support denominator fell from 22 to 19, not 22. Empty or unsupported map modes failed with exit 1.
- **Missing excerpt: improved.** A path to `missing-excerpt.md` failed, with `SOURCE-SUPPORT 21/22` and the required missing-path error.
- **D-M4-1 — declared line span is not enforced (blocking).** E1’s map locator was changed from `gate-witness-excerpt.md:7` to `:6`; the exact anchor still exists only at excerpt line 7. The checker nevertheless returned exit 0 and `SOURCE-SUPPORT 22/22`. The script parses/stores `span` (`M3-support-script.patch:100-108`) but `run` calls `grep_anchor(anchor, excerpt)` without passing or checking that span (`:201-205`; `grep_anchor` is at `:155-169`). Fix: require a valid line span and require at least one grep hit to fall inside it. This violates the requested wrong-line failure and R9’s path+line-span map contract, so C2 is not fully closed.
- **D-M4-2 — receipt shape is per-cluster.** `corpus/tools/README.md` gives two direct commands and the CLI accepts one cluster argument. A deterministic shell one-liner can run both and returns the two receipts (`22/22` and `10/10`), but it emits no aggregate `32/32`. If “one reproducible support command” requires one invocation/aggregate denominator, the current proposal does not meet that stricter reading; phase-2 integration should settle this explicitly.
