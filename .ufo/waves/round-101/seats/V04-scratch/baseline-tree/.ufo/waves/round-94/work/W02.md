## Owned files

- `corpus/tools/map_obligations.py` — stdlib CLI enumerating entity `first_appearance`, each entity claim, every relation, and every timeline record. It accepts one canonical JSON pointer and one source ID per map row; reports stable `missing_obligation`, `duplicate_mapping`, `phantom_obligation`, and `source_id_mismatch` findings. Unsupported/legacy/co-mapped grammar, malformed inputs, foreign/traversal paths, and symlinks return `ERROR` (exit 2). Verdicts are `PASS`/0, `FAIL`/1, `ERROR`/2.
