## Findings & named debt

- **R8 decision:** resemblance alone does not establish influence. The lore integration editor opens a dated, neutral `possible influence: unverified` note when evidence beyond a commonplace motif triggers review; this records a question, not source use. R2 requires both a creator confirmation and no contrary source-specific evidence after review. Confirmed use of only a general motif can remain as new fiction with the R8 marker and independent in-world support; unresolved influence is not silently R2 and the affected detail is withheld. Compared with D1, D2 does not apply `external-only / unverified inspiration` to an unconfirmed possibility; it reserves that marker for established source use/general-motif disposition.
- **R9 decision and explicit D1 divergence:** D2 keeps the excerpt labelled `translation` and records `version: unknown`. If a reliable bibliographic record ties the named translator and delivered passage to a named source work, the excerpt may support only the translator's rendering; it cannot support original wording or an edition-specific variant. If only the translator is known or the source-work link is unverified, R5 support fails. D1's proposal is stricter: no R5 support until source text/version identity is established (`.ufo/waves/round-90/D1.md:79-82`, `patches/D1-decisions.md:23-31`). The concrete integration choice is whether a verified work-level tie is sufficient when the precise edition/version is unknown; neither proposal treats translator name alone as sufficient.
- **R10 decision:** repeated names/IDs trigger comparison, not identity. Source-backed identity, field, and occasion must overlap before a contradiction can enter the live register. D2 adopts a README audit note for compared-and-dismissed overlaps and a candidate/missing-evidence note in `l0-questions.md`; only supported incompatible pairs go in the register. The current register remains absent/correctly empty: r87 has one local Hara/Sen contradiction, but r88-M3 has distinct entity names/IDs and no shared referent with r87; the R89 demo is hypothetical.
- **Reviewer gap:** D1's decision patch/report landed and were read. E2, T1, R1, J3, and C7 were absent at the deadline, so no independent wording, cross-verifier, retroactivity, register, or discipline-review outcome is available from those seats.
