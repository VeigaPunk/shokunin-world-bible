# R01 — boundary-doc checker recovery

Axes in scope: **depth, coverage, calibration**. This is a scoped corrective work report, not a scalar score or an admission/promotion verdict. No commit or push was made.

## Work and changed paths

- `corpus/tools/boundary_doc_check.py`: replace substring-only C9 checks with a SHA-256 gate over the frozen document; verify delivered `check_bible.py` bytes before any receipt replay; validate the legacy full-form citation against the pinned baseline checker; resolve defaults from the script's repo root; convert missing, unreadable, and invalid-UTF-8 inputs into named failures; add isolated CLI self-test mode.
- `corpus/tools/boundary-doc-contract.json`: persist document/checker pins, full revisions, the legacy anchor mapping, scope statement, and independently specified self-test expectations.
- `.ufo/waves/round-93/recovery/R01.md`: this report.

This seat did not edit the pinned boundary document, delivered child checker, or receipt input bytes. The frozen-document gate catches comment-parked C9 markers and a wrong bare citation as `document_drift`; it does not parse every bare citation or validate prose semantics.

## Findings and severity

- **High — frozen-document false certification:** a modified document could keep required C9 substrings in a comment or change an in-range bare anchor and still pass the prior checks. The exact document digest is now checked before replay; the self-test exercises both variants, each with stable finding ID `document_drift`.
- **High — changed child checker executed before rejection:** the pinned `corpus/fixtures/check_bible.py` bytes are now checked before replay. An isolated drift copy containing a top-level exception produces only `checker_drift`; it is not executed.
- **Moderate — baseline anchor range used the wrong revision:** `check_bible.py:212-224` is explicitly mapped to full revision `5eb9451baff217c19d5786405f9b2aa500b7c1b7`; its range uses that revision's checker bytes after SHA-256 verification. Other explicit full-form anchors use the delivered checker pin.
- **Low — path/encoding errors lacked named failures:** missing, unreadable, and invalid-UTF-8 documents/checkers now fail with named IDs and no traceback.

## Bounds and remaining limits

`CERTIFIED` is explicitly bounded to frozen-document drift, receipt replay, explicit full-form anchor ranges, and document structure. It is **not** generic semantic or AST/content-signature validation. Bare anchors are not individually range-checked; changes to the manually audited frozen document are caught by its digest. The gate does not defend against coordinated edits to the gate and its colocated contract, and it does not make claims about the truth of the document's prose.
