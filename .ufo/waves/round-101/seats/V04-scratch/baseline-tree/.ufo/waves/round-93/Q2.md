### Roster arithmetic in the source spec

Exact parser command:

```sh
python3 - <<'PY'
import re
from pathlib import Path
text=Path('.ufo/waves/round-93/wave-spec.md').read_text()
block=re.search(r'(?ms)^## Roster \(32\)\s*\n(.*?)(?=^Integration unchanged\.)', text).group(1)
headers=list(re.finditer(r'(?m)^([A-Za-z0-9-]+) (\d+): ', block))
rows=[]
for i, header in enumerate(headers):
    end=headers[i+1].start() if i+1<len(headers) else len(block)
    body=block[header.end():end]
    ids=re.findall(r'\b(?:CB-audit|[A-Z]{1,2}\d+[a-z]?)\b', body)
    rows.append((header.group(1), int(header.group(2)), ids))
all_ids=[seat for _,_,ids in rows for seat in ids]
role_only=int('CERT tool author' in block)
print('group_declared_counts='+','.join(f'{name}:{count}' for name,count,_ in rows))
print('group_explicit_id_counts='+','.join(f'{name}:{len(ids)}' for name,_,ids in rows))
print(f'declared_total={sum(count for _,count,_ in rows)}')
print(f'explicit_ids={len(all_ids)} unique_explicit_ids={len(set(all_ids))}')
print('explicit_id_list='+','.join(all_ids))
print(f'role_only_CERT_tool_author={role_only}')
```

- **D-r93-operational-budget — partial.** The tracked helper completed the full deadline poll, but its hit path lacks the terminal receipt shape. The spec still has no numeric scratch budget or closure policy.

Three measurable r94 improvements:

1. **Freeze a fully enumerated roster before dispatch.** Require 32 explicit, unique seat IDs and one manifest row per slot; no role-only identity and no unnamed slot. Gate: `declared_count = manifest_rows = unique IDs = 32`, with zero unresolved identities.
2. **Make validation reconcile identities and artifacts, not just counts.** Check each report stem and patch/data path against exactly one manifest seat or an explicit non-seat class; reject missing, duplicate, and unknown IDs. Run a valid case and negative controls (including 32 unrelated filenames) before dispatch and at cutoff. Target: zero unmapped artifacts; the unrelated-name control must exit nonzero.
3. **Gate dispatch and closure on reproducible operational receipts.** Land the manifest and validator before the wave starts; at closure record the 20-minute helper receipt and a validator run, with a runner allowance of at least 1,500 seconds for a 1,200-second poll. Add terminal-shaped hit/deadline/signal receipts and a numeric scratch policy (for example, ≤200 entries per seat, ≥5% free inodes, named fallback, and a residue sweep). Targets: 100% dependency polls have one terminal receipt and zero round-tagged scratch residue.
