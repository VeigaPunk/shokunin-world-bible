Their rows also retain the obsolete tentative wording (`.../r41-vela-direct-bell/vela-clause-map.md:7-10`; corresponding r43 lines 7-10). Correcting the maps would stop a reader using that map as the local clause guide from being given a false quotation.

But the defect and its interpretation are not undisclosed: r41's `strength-contrast-map.md:3,5` explicitly contrasts r40 and r41 and calls the fixed record under-specific; r41 adjudication records the stale inherited map and says the contrast map identifies the limit (`reports/r41-axis-adjudicator.md`, “Independent evidence”). Thus the repair improves the immediate local artifact, but it does not introduce the underlying source/record distinction or newly reveal the stale-map fact. Whether removal of a misleading adjacent quote is enough calibration gain beyond the existing warnings is a human usability judgment, not established by map byte changes alone.

- Exact planned delta: only `r41-vela-direct-bell/vela-clause-map.md` and `r43-jorin-vela-sighting/vela-clause-map.md` change. The fixed JSON “took to be” remains a logically compatible, weaker/under-specific summary—not false or contradicted. No promotion into an objective bell event, shared Bell-7 occasion, chronology, Sella/envelope absence, canon, or rights/permission.
- Checker cleanliness and unchanged JSON cannot validate prose-map fidelity; the test is manual comparison of each map with its local excerpt. An inherited-byte comparison that treats the two repaired maps as unchanged would be a provenance regression.

## Falsifiable go/no-go

**Conditional go** for the narrow documentation correction only if independent review confirms (a) both maps now quote the exact direct local source and remove obsolete tentative clauses, (b) they retain attribution and distinguish the weaker fixed JSON without calling it false, and (c) the exact two-file Markdown delta above is reported honestly, with r40 control and r41/r43 JSON/excerpts unchanged. This can improve local calibration by eliminating an actively misleading clause map; it does not prove broader reviewer calibration or a new source distinction.

**No-go / no material calibration admission** if the claim is merely “the stale map is known,” because prior r41/r43 warnings already establish that; if review finds the strength map and Jorin warning make the stale quotation non-misleading in actual use; if either repaired map retains the r40 quote; or if any source/record/provenance boundary is blurred. Measure the decision by a reader given the active excerpt and local clause map (not the contrast/adjudication reports): can they accurately report Vela's direct attributed identification, distinguish the weaker compatible JSON, and avoid asserting objective bell fact? Failure to improve that bounded reading, or any hidden third-byte change, falsifies go. A successful correction is a useful cleanup, but the calibration-axis gain remains fragile against the already-recorded warnings.
