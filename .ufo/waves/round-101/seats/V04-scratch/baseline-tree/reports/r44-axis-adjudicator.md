- **Coverage — unchanged.** No established invalid-input class gains a diagnostic, no r44 fixture or checker change was made, and the place-actor CLEAN probe lacks an explicit rule it violates. Legacy replay preservation alone is not an improvement. A speculative kind rejection does not count as coverage.
- **Depth — unchanged.** No new attested narrative link, supported entity ontology, source comparison or event meaning was added. The synthetic probe adds no lore evidence.
- **Calibration — unchanged for the delivered artifacts; proposed change risks harm.** The existing generic schema and outputs remain byte-identical. An unconditional character-only rejection could falsely flag legitimate place-, faction-, or item-subject timeline events and convert an unstated editorial preference into an asserted violation. Those event types are plausible under the present generic contract, not proven canon examples; risk is sufficient to block this ungrounded move, not a claim that actual harm occurred.

**Falsifier / next admissible experiment:** obtain an authoritative, explicit project contract that either (a) all timeline `entity_id` references must identify characters or (b) an encoded, clearly identified event class requires a character actor. Distinguish that class from legitimate non-character-subject events, then run a paired character/non-character probe against that scoped rule, independently verify unchanged old fixtures and check that valid other event subjects are not rejected. If a valid in-scope place/faction/item event is documented, it falsifies any universal character-only guard. Absent such a contract, keep the generic checker behavior and reject r44.
