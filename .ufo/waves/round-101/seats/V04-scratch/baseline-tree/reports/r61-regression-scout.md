## Boundary

Source-ID membership is an input-index/reference-integrity result only. An unknown ID in a successfully loaded table is not proof that no excerpt exists elsewhere; a unique ID is not proof the cited text supports a claim. A load failure says still less about the contents of the unavailable table. Do not infer real/fictional-world absence, source-text truth or support, chronology, canon, ownership, license, or permission from any status or diagnostic. No source content or rights review is in scope.
