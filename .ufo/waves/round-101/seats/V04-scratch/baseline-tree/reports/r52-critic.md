# Round 52 critic — source-status qualifier materiality and falsification

## Scope and evidence

Read-only critic assignment. I inspected `.shokunin/lore/corpus/fixtures/check_bible.py`, its README, the Round 52 declaration in `.shokunin/lore/LOG.md`, and prior round reports. I made no checker, fixture, README, LOG, or commit changes. The declared proposal is not yet an implemented candidate; this report does not claim probe output or regression results.

## What the source establishes (and does not)

`check_bible.py:53-68` builds source-ID counts and classifies a citation as `unknown`, `unique`, or `ambiguous`; `source()` reports the latter two non-unique states locally (`:64-78`). Timeline rows call `source(row['source_id'], ...)` independently (`:242`). Occupancy has a separate gate: only a uniquely indexed actor, uniquely identified place of kind `place`, and nonnegative tick enter the slot (`:233-250`). That gate does **not** inspect the event’s source status. The raw collision can therefore coexist with a local ambiguous-source finding. The raw collision itself is an input-field result: two rows share an actor ID/tick and name distinct resolved places. It does not establish either source’s textual support, whether the event prose entails its `place_id`, or story/canon truth.

The exact analogous caution is Round 7's item provenance chain, not a general rule for all structural diagnostics: `.shokunin/lore/reports/r7-provenance-scout.md:24-44` observed that chain-break output continued despite duplicate cited source IDs and proposed clearly labeling chain structure as not sourced canon; README Round 7 says duplicate IDs are ambiguous citations (`.shokunin/lore/corpus/fixtures/README.md:121-139`). That precedent supports considering a provenance qualifier but also exposes risk: Round 7's output had a chain finding whose apparent evidentiary force was directly affected by citations. Occupancy is derivable from the event input fields regardless of source uniqueness, so a qualifier can overstate source dependence if phrased as though ambiguity weakens the raw collision itself.

Prior Round 12 addressed a different identity uncertainty: duplicated **actor entity IDs** yielded a definite-looking double booking; adjudicator admitted the ambiguity guard but explicitly noted per-row noise and that events/citations did not establish canon (`.shokunin/lore/reports/r12-axis-adjudicator.md:5-19`). Round 52 must not conflate ambiguous source IDs with ambiguous actor/place identity. With a unique actor and valid places, the raw collision remains structurally warranted even if cited source identity is ambiguous.

## Falsification and risks

The materiality case is plausible but weak absent a demonstrated misreading: generic `VIOLATION: ... double-booked` can look like an asserted narrative conflict, while neighboring ambiguous-source diagnostics reveal a problem. Yet the checker and README already bound the tool as structural/citation-ID checking, the CLI summary says no canon changed, and the event rows remain inspectable. Adding the long qualifier to every collision involving an ambiguous citation could create noisy verbosity for a rule whose operands are independently visible in the input. One ambiguous source may affect one or both rows; qualify only the affected collision(s) if the exact wording clearly says the *collision finding* is input-structural, not sourced canon—not that the source proves/disproves the location, that the collision is false, or that source ambiguity negates the raw input fact.

False premise to reject: unique source ID is not source-text verification. A clean citation ID does not prove that the fictional source says the actor was at that place; hence unique-source collision is not thereby a sourced-canon conclusion. Conversely ambiguous ID neither proves nor disproves the fictional location/source prose or canon. Do not imply the ambiguous source is false, that duplicated source rows represent different source documents, or that occupancy is impossible. Keep every raw collision visible and retain duplicate-ID plus local ambiguous-source diagnostics; no suppression, rekeying, source selection, or inferred canon. The proposal must also test source status per event, including only one colliding row ambiguous and both ambiguous, and confirm unrelated unique-source diagnostics/messages unchanged.

Noise/harm falsifier: if the qualifier is repeated for each affected collision while the existing local ambiguity diagnostic already suffices, and blinded or otherwise independent readers do not misclassify the raw collision as source-verified after seeing the unqualified output, the claimed calibration gain is unproven and the added text is noise. Conversely, a reproducible reader interpretation that treats the raw finding as a sourced/canon claim, corrected by the narrow qualifier while preserving the collision, would support materiality. Do not count a string-only improvement as proof that source prose was evaluated.

## Go / no-go

**Conditional no-go pending evidence.** This is a viable calibration hypothesis, not established material gain. Go only if a paired, schema-valid temporary probe (outside corpus) shows: (1) unique-source control has exactly the existing raw `double-booked` finding; (2) duplicate-source variant retains that exact raw collision plus all duplicate/local ambiguity findings and adds an unambiguous qualifier only to the affected collision; (3) neither row/event nor the collision is suppressed, and no source is chosen; (4) exact baseline regression replay shows no unrelated output change (or every affected existing output is enumerated and justified); and (5) independent review demonstrates the qualifier reduces a concrete source-truth misreading without suggesting source text was checked. Include one-ambiguous/one-unique and both-ambiguous cases, same-place/no-collision and noncollision controls, and preserve raw occupancy attribution. If the only evidence is analogy to Round 7, or the label is interpreted as downgrading the input-field collision or asserting an implicit source-truth premise, **no-go/reject**. If admitted, calibration alone is eligible; depth and coverage are unchanged, and any demonstrated suppression/noise is harm requiring rejection.
