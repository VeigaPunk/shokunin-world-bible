## Potential Bell-7-specific remainder

There is a real *case-specific dependency* not explicit in r74's rows: before comparing reported locations as incompatible, an editor must test whether the accounts refer to one uniquely identified ringing/occasion. r35 assumes the fictional sole-ringing/date descriptions align; r36 demonstrates that the shared label alone cannot repair a seventh/eighth-day mismatch. A request to establish event/occasion linkage (not simply ask for “time evidence”) could therefore be distinct from r74's question whether two slate readings concern the same surface and in what temporal order.

A second possible distinction is the **role separation** between (a) identifying Tarin as observer and Sella as observed person, and (b) identifying the Harbor observation scene versus Sella's own claimed location. The r35 map already states this distinction, however, so a table row only restating it is duplication. It gains value only if it names evidence that would independently discriminate a mistaken person/place alignment from a correctly aligned but incompatible account. Neither the fixture IDs, JSON pointers, tick 3, nor a source citation can do that work by themselves.

These are candidate gaps, not established facts or evidence. No source/capture independence row is uniquely Bell-7-specific: r74 already covers provenance-bearing contemporaneous material, while the r35 notes are authored fictional excerpts with no authentication or provenance claim.

## Assessment / novelty bar

**Mostly duplication; narrow potential novelty, not yet demonstrated material gain.** The distinctive Bell-7 question is an *occasion-identity gate* before the location conflict analysis, with the r36 mismatch as a concrete negative control. A table could be useful if it operationally distinguishes what to request when (i) occasion linkage fails/is ambiguous versus (ii) it succeeds, and separately identifies what evidence could test the observer/person/place alignments. It must not treat the source's self-applied Bell-7/date as independent anchoring, or imply such evidence exists. If it just presents the r74 three-row template applied to Bell-7 and restates r35 limitations, the Round 82 novelty criterion is not met. This scout cannot establish that an independent editor would choose a different next action; that requires the proposed before/after test.
