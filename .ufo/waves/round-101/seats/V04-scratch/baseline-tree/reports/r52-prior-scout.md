## Risk and scope judgment

There is a bounded calibration risk: a bare `double-booked` label sounds categorical to a reader, although the checker only establishes a collision among input rows and does not establish that either fictional source supports the location assertion. With an ambiguous source ID, local source ambiguity already warns that citation identity is unresolved; however, it does not explicitly label the *separate* occupancy finding as input-structural. R7's principle (“structural ... not sourced canon”) is analogous enough to justify a tiny wording test, but its precedent does not prove an occupancy qualifier is needed: README already explains the checker validates pointers, not citation truth (`README.md:51-54`), and its occupancy explanation says the event records trigger the rule without proving canon (`README.md:256-265`, `443-468`). Avoid redundant qualification for all collisions absent evidence of actual reader confusion.

Crucially, retain raw collision visibility in either unique- or ambiguous-source case. A duplicated source ID neither negates nor confirms the event's fictional location assertion, the source prose, or canon. Conversely a unique source ID is identity resolution only, never text support (`README.md:36-41`, `51-54`, `265`; `LOG.md:93-97`). The source ambiguity must not gate occupancy, choose a source row, imply two source records disagree, or turn this diagnostic into a sourced contradiction. Do not conflate with r12's ambiguous actor rule.

## Falsifiable go/no-go

**Conditional GO for a narrowly scoped calibration probe, not blanket rewording:** construct a schema-valid pair with unique actor/place/tick and different places, both citing a duplicated otherwise-valid source ID; pair it with the same records under a unique source ID. Preserve identical raw `double-booked` collision in both, plus source duplicate/local ambiguity findings only in the ambiguous-source variant. If testing wording, qualify only the ambiguous-cited collision as an “input-structural finding, not sourced-canon” (or equally short wording), leaving the unique-source message and every collision observable unchanged. Require exact pre/post raw outputs for all baseline cases and byte-identical fixture inputs; inventory any already affected output rather than claiming unchanged replay.

**NO-GO for checker-policy change or suppression now.** Prior art does not show ambiguity breaks occupancy's input predicate, and no current active fixture proves a material reader misclassification that requires changing the general diagnostic. Admit a wording move only if the controlled pair verifies the above and an independent reader/test demonstrates that the added narrow qualifier prevents a sourced/canon overreading not already prevented by existing guidance. Reject if the qualifier is redundant/noisy, obscures the collision, affects unique-source output, or implies ambiguous source ID disproves the represented place. Falsifier for the risk: readers consistently interpret existing `double-booked` output as a collision among asserted input rows, not as source corroboration, including the ambiguous-ID case. Any eventual candidate must keep depth/coverage unchanged and improve calibration only; no claim that either source text supports or refutes fictional location/canon.
