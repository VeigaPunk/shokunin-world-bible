# W16 — C2 trust-boundary audit

**Axis:** calibration. **Scope:** audit C2 parser trust boundaries only; no product edits.

## Bounded finding

At audit time, `corpus/tools/map_obligations.py` and `corpus/tools/map-obligations-contract.json` were absent (lane globs returned no matches). The declared interface is in `.ufo/waves/round-94/wave-spec.md:21-27`: compare raw JSON obligations to canonical `file.json#/pointer` map rows; malformed JSON, invalid paths, and unsupported bracket/prose/co-mapped pointer grammar are could-not-evaluate (exit 2), never an empty successful inventory. There is no implementation to attack, so these C2 cases remain untested and no C2 PASS/admission is claimed.

The existing excerpt resolver in `corpus/tools/support_check.py:149-169` resolves candidates strictly and requires the resolved file to remain under the resolved cluster directory. A tiny isolated control confirmed that this guard rejects relative traversal, an absolute outside-cluster excerpt, and a symlink escaping the cluster. All three returned `RESULT FAIL`, exit 1, with `excerpt path missing or outside cluster`; the local in-cluster control returned `RESULT PASS`, exit 0. This is evidence only for the existing Markdown excerpt checker, not the absent JSON-pointer parser.

One boundary distinction: `support_check.py:392-408` accepts an explicit `--map` path based on `is_file()` without requiring it to be under the cluster. The isolated local control used a map file beside (not inside) the cluster and passed. That is an explicit map override, not proof that excerpt paths escape; do not reuse it as a raw-source pointer guard.

`parse_map` at `support_check.py:71-139` parses Markdown tables and does not parse raw JSON or JSON Pointers. Thus malformed JSON and unsupported pointer syntax could not be exercised on the current implementation. For C2 implementation review, require exit 2 plus stable finding IDs for: `../outside.json#/…`, an absolute/foreign source path, a symlink resolving outside the input root, malformed JSON, and bracket/prose/co-mapped pointer syntax. None may produce an empty inventory or `RESULT PASS`; reserve exit 1 for an evaluated obligation-comparison failure.
