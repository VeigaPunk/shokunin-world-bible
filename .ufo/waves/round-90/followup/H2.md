  + 4 new; 0 changed tuples, 0 exit changes, 0 stderr, B1=B2 receipts byte-equal, all 160

  (delivered == X2+X3 composed, zero fuzz). No axis harmed; nothing here is a trade.
- **FN-2 anchor:** the pair is in the census manifest at both ends and stays tuple-identical

  manifest text delta: `corpus/fixtures/README.md` and `corpus/knowledge/holder-assessment-boundary.md`
