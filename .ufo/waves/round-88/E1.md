## Findings & named debt

- **Mixed-stop attribution:** JCAL4 found the current wording literally reports an unassessed comparison and a real ambiguity at the correct location, but misleadingly frames the later ambiguity as the operative cause despite an earlier unknown-source stop. Candidate 3 alone avoids “because” but still does not identify the actual first cause. The draft uses retained first-stop state and chain-local locators.
- **Shape-invalid + ambiguous holder:** the baseline probe above gives 2 violations and no disclosure. Template 1 is a first-stop variant to describe this path without silently skipping it or claiming a later ambiguity was first.
- **Non-holder stops:** unknown-source/dangling-holder cases need an explicit first-cause disclosure even when no holder ambiguity exists.
- **Named debt — same-record cause aggregation and pre-loop suppression scope:** if multiple invalid findings occur on the earliest stop record, the implementation must report the full same-record cause summary or define a stable precedence; wording must not imply an unmeasured order. Cases where comparison never becomes eligible before the record loop (for example unavailable sources, non-item entities, or duplicate item IDs) are not resolved by these record-stop templates and need an explicit scope decision.
- Templates are alternatives for a single disclosure per record, not additive messages. This avoids reproducing JCAL4's redundant notice at the stop record.
