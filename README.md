# shokunin-world-bible

Fictional-world records — characters, places, factions, items, the
relations among them, and the timeline — with a checker that reports
contradictions and does not resolve them.

The lane id is `lore`. Rank is shonen. There is no root `SKILL.md`.
The boundary is `PROVINCE.md`. The checker and the fixtures are the
craft you can run.

## The job

`PROVINCE.md` owns those records, consistency verification, and sourced
inspiration. A canon claim needs an in-world citation. A contradiction
is reported, not silently repaired. Real-world rights questions and
game-mechanics verification are refused. Rights, attribution, and
AI-training permission stay distinct questions; the reference ledger is
`corpus/knowledge/reference-ledger.md`.

Writes stay in this repository, its own fleet round report, and allowed
append-only L0 questions. Sibling repositories are read-only.

Linguistic and cultural *systems* — languages, myths, costume lexicons —
are generated by [kotodama-shokunin](https://github.com/VeigaPunk/kotodama-shokunin)
and handed off. This lane records them once they are canon, and checks
them. It does not design them.

## Check a bible

`corpus/fixtures/check_bible.py` validates a directory of JSON arrays
(`sources`, `entities`, `relations`, `timeline`, and contradictions
when present). It prints `VIOLATION:` lines and exits 1 when the
directory is inconsistent. A clean directory prints
`CLEAN: schema, citations, relations, timeline; 0 violations`.
The docstring's promise: report, never resolve.

```sh
python3 corpus/fixtures/check_bible.py corpus/fixtures/consistent
```

`corpus/fixtures/README.md` is the exact run book: which directories are
the positive case, which are the malformed and contradictory cases, and
what a clean run does not prove. `corpus/README.md` indexes the same
fixtures and the preserved stdout under `corpus/live/runs/`. The
rejected round-4 name inputs live only in `corpus/live/rejected-r4/`.
