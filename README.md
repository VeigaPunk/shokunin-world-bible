# shokunin-world-bible

**Fictional-world records — entities, relations, timeline — with
mechanical consistency and a citation, or it is not canon.**

Lane name: **lore-shokunin**. A **shokunin lane** minted and trained
under the [shokunin](https://github.com/VeigaPunk/shokunin) skill.

**Wiki:** [lane overview](https://app.devin.ai/org/veigapunk/wiki/VeigaPunk/shokunin-world-bible?branch=main)

## Domain

From `PROVINCE.md`: characters, places, factions, items, relations,
timeline events — with consistency verification and sourced inspiration.
Real-world reference works are cited with the art ledger's discipline:
attribution, rights, and AI-training permission stay distinct questions.

This lane **records and verifies** canon. It does not generate languages
or cultural systems —
[kotodama](https://github.com/VeigaPunk/kotodama-shokunin) designs those
and hands them off via
`corpus/knowledge/synthesis/worldbible-integration-contract.md` in the
kotodama repo. Lore decides whether a handed-off system enters the
bible.

## What it refuses

Claiming canon without an in-world citation. Silently resolving
contradictions. Real-world rights claims. Game-mechanics verification
([game-dev-2d](https://github.com/VeigaPunk/shokunin-godot-2d)). Sibling
repositories and domain source trees remain read-only.

Writes only this repository, its own fleet round report, and allowed
append-only L0 questions (`l0-questions.md`).

unknown; rounds are non-author-verified. See the fleet
[README](https://github.com/VeigaPunk/shokunin#readme).
