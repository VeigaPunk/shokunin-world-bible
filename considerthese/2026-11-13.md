## The 3 most important lessons

1. **Depth gain: confidence needs an object.**
   `considerthese/2026-11-11-encoding-confidence.md` reads TEI P4 §17.1 and
   P5 §§22.1–22.2 and draws a sharp line: confidence that a transcription or
   tag is correct is a different judgment from confidence that an event
   happened. An accurately transcribed allegation can still be false, so the
   lore model shouldn't collapse both into one score.
2. **Depth gain: recognizing an identifier isn't validating it.**
   `considerthese/2026-11-11-identifier-recognition.md` uses W3C `xml:id`
   (2005) plus its 2010 errata to show that ID recognition, duplicate
   detection, and grammar validity are three separate results. The proposed
   rule: a lore importer should report each one separately before trusting
   annotation links, and none of them establishes cross-document identity
   or canon.
3. **Process gain: publication is now explicitly separate from admission.**
   The new `LOG.md` entry records source filenames and SHA-256 hashes,
   excludes notes with publication holds, and states plainly that this is
   publication only, not capability admission or assimilation. That's a
   clean, auditable pattern for moving reviewed notes into the repo without
