## One-axis test, falsifier, risks

Calibration axis only. Build temporary byte-matched controls with the four non-source JSON files identical and `sources.json` varied: unavailable (missing, malformed/duplicate-member, and nonarray as applicable), loaded `[]`, loaded partial with some matching and some missing IDs, and loaded ambiguous duplicate IDs. Include direct entity/relation/timeline/provenance citation references and a uniquely pointed ledger event so both ordinary unknown/ambiguous diagnostics and ledger-derived “no resolvable source_id” are tested. Capture complete stdout/stderr/exit, not selected lines. Proposed rule (not current behavior): retain file-level load/shape error; suppress only index-derived unknown/ambiguous/certainty outcomes when the whole source table is unavailable; preserve actual unknown/ambiguous findings for successfully parsed empty/partial/duplicate arrays; retain independent schema, entity, relation, timeline tick/dependency, and ledger event-ID/shape findings. R32 means all-invalid-but-valid-array is still “available” unless a separately justified rule says otherwise.

Falsify/NO-GO if (a) matched replay does not show unavailable-index-derived definite unknown/no-resolvable conclusions that are misleading beyond the direct loader error; (b) loaded-empty or loaded-partial output changes; (c) any independent error disappears; (d) duplicate-member/shape failure is incorrectly treated as successful availability; or (e) current documented contract defines parse failure as intentional empty input. A prospective harm is losing useful per-reference triage and combined ledger/link findings when the table cannot be read; R60 already incurred an analogous visibility trade-off for entity dangling lines. Reports/UI must state these lookups are unassessable due to file failure, not CLEAN, resolved, or absent. More severe risk: source gating could accidentally bypass provenance chain validation or ledger event-ID checks if whole consumer loops are skipped; test those explicitly. Preserve loaded valid duplicate-source ambiguity and malformed-row screening behavior.
