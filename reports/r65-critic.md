# Round 65 critic — forward-source eligibility and material calibration

## Scope and observed baseline

**Independent verdict: NO-GO on material calibration as presently evidenced.** The proposed change is a plausible convention choice, but the evidence establishes neither that a forward citation must be unique to demand a reverse witness nor that suppressing the structural finding improves repair. Do not implement on the declaration alone. This verdict concerns calibration only; it makes no source-prose, canon, or rights claim.

Current code `.shokunin/lore/corpus/fixtures/check_bible.py` has two distinct operations. In the generic relation loop, each row calls `source(row['source_id'], ...)`, yielding unknown/ambiguous source diagnostics as applicable. Later, the allied-faction pass filters eligible endpoints to unique faction entities, and declares a reverse witness only if the reverse row cites a unique source (`source_status(candidate['source_id']) == 'unique'`). It does **not** test the forward row’s source status before emitting `lacks a sourced reciprocal relation`; it emits that finding if no qualifying reverse exists and sources are available. This is current behavior, not proof that either policy is semantically correct.

## Materiality challenge: structural condition versus forward source

The move assumes a derived “missing reciprocal” conclusion should be conditional on the forward row’s source resolving uniquely. An equally coherent structural convention is that every supplied, eligible faction edge is checked for a reverse edge that itself has an adequate citation; then an unknown/ambiguous forward citation is an independent defect, while missing reverse structure remains separately actionable. In the latter convention, the forward citation does not determine whether the row’s direction has a reverse. The current checker’s separate generic citation check and reciprocal check implement something close to that. Conversely, a policy requiring a uniquely cited forward assertion before testing its reciprocal is defensible if the finding means “this sourced assertion lacks a sourced reciprocal.” The existing phrase says “lacks a sourced reciprocal relation,” but is not explicit whether forward qualification is included.

Potential benefit of gating is avoiding a relation-local finding whose premise (a qualifying forward assertion) is unresolved. Potential harm is losing a useful structural repair pointer: the operator would still see the citation defect but would no longer be told which direction has no reverse. A source ambiguity/unknown diagnostic does not name that directional omission. The forward row is present in the supplied input and endpoint eligibility is independent of source metadata, so suppressing the finding is not merely removing a duplicate citation error. The round declaration itself identifies this repair-pointer loss. No evidence currently compares operator action or output utility under the alternatives. R7’s reverse-side policy cannot simply be generalized: a candidate reverse is the proposed *witness* and its qualification is directly germane; the forward row is the *subject* whose reverse is being checked.

Thus the key falsifier is not merely that a forward-unresolved row can be constructed. It is whether, with all other input bytes fixed, suppressing its missing-reverse finding removes a materially misleading result rather than a useful repair pointer. A reverse-side ambiguous witness must remain non-qualifying, and a uniquely cited forward with absent reverse must retain the finding. Unknown and ambiguous forward variants should retain their own direct source diagnostics, all endpoint/type/other-relation findings, and produce a deliberately justified distinction in the reciprocal finding. If the only evidence is a hypothetical rule preference, this is not demonstrated material gain.

## Conclusion and limits

The code path and existing fixtures establish that forward-source qualification is currently asymmetric with reverse-witness qualification. They do not establish that the asymmetry is erroneous. The proposed gate can improve wording/calibration if it avoids treating an unresolved forward citation as a sourced assertion, but can harm repair utility by hiding the absent reverse direction while leaving only a generic citation error. With no matched forward-unknown/ambiguous outputs, operator-benefit evidence, or non-author adjudication, **NO-GO on material admission**; permit further probing only. The checker validates supplied structure and identifier membership, not source prose, evidential truth, canon, chronology, rights, license, or permission. No such claims are made here.
