Depth remains unproved until the actual rows show that distinction and a non-author editor confirms it helps decide what to seek next.

## Hypothesis and calibration risks

The three proposed possibilities—separate surfaces, one surface at different unverified readings, and an inaccurate report—are plausible *questions*, not findings. R73 provides no basis to prefer any one, to treat the alternatives as exhaustive, or to infer inaccuracy from the sources’ “unverified” labels. “One surface at different readings” must remain conditional: it must not imply a stable inscription, that either reading occurred at a known time, or that a change took place. “Inaccurate report” must not turn either report into a liar/false witness claim or select which account is wrong. Avoid saying the table will “resolve” the discrepancy; it can only name evidence that might clarify it.

Concrete requests can distinguish the options without inventing evidence. For example, label them as requests for *possible* evidence, not as documents known to exist:

| Conditional possibility, not finding | Distinct evidence question that could bear on it | Limit to state in the table |
|---|---|---|
| The reports concern different surfaces. | Is there any independently attributable account or description that identifies the two surfaces separately? | No such identification is presently cited; this possibility is not established. |
| The reports concern one surface read on different, presently unknown occasions. | Is there any attributable evidence that identifies a common surface **and** independently places each reported reading, without assuming an inscription persisted between them? | Neither a common surface nor either reading time is established; do not infer a change. |
| At least one wording report is inaccurate. | Is there any independent basis for assessing either reported wording (for example, a separately attributable transcription, if one exists)? | The existing accounts alone do not establish error, which report if any is inaccurate, or why. |

This is an illustrative test, not an r74 artifact or claim that these records exist. A cleaner table may use other discriminators, provided each ask is distinct and conditional. In particular, “an original slate,” “a dated copy,” or “a registrar’s record” must not be described as extant; they are only possible evidence types if explicitly framed that way. The categories can overlap—for example, a report could be inaccurate even if the reporters saw different surfaces—so call them non-exhaustive possibilities, not a mutually exclusive three-way diagnosis.

## Provisional falsifier

**Depth: conditional, not yet demonstrated.** Admit only if the delivered note adds a usable next-evidence decision beyond r73’s unresolved sentence: separate, actionable tests; explicit hypothetical/non-exhaustive status; and resolved pointers to the existing reports. Reject if it only restates uncertainty, if evidence requests are generic or duplicate one another, or if the rows smuggle in an extant artifact, common surface, timeline, changed inscription, witness error, or source ranking. The latter also risks calibration harm. A carefully framed table need not harm calibration; it should preserve the distinction between authored report and established fact already maintained by the r73 claims/maps.

The cited excerpts are authored fictional reports, not independent evidence about a real slate. Citations establish attribution in this fixture, not truth. I make no source-truth, canon, rights, or game-mechanics inference. No checker run can adjudicate these prose-level distinctions.
